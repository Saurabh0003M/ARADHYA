# Claude Agent SDK (Anthropic) – Pricing and Limits

Anthropic’s Claude plans (as of Aug 2026) are Free, Pro, Max 5×, and Max 20×. Pro is $20/month (or $200/yr) and Max plans are $100 and $200/mo【16†L288-L296】. In practice, Pro users see only ≈40–45 messages per 5h window (~160–180/day), whereas Max 5× sustains ≈225/5h (~900/day) and Max 20× ≈900/5h (~3,600/day)【16†L310-L314】. A heavy agent (200 turns/day with ~10 model calls each ≈2,000 calls/day) would far exceed Pro or Max 5× limits – essentially requiring Max 20×. Without a subscription, one can use Claude’s pay-per-use API: e.g. Sonnet-5.5 is $2/MT input + $10/MT output through Aug 2026【16†L278-L285】, so ~6–12¢ per 1,000 tokens. (For 2k calls at say 200 tokens/call ≈400k tokens/day, that’s ~$60–$120/mo.) The Claude API enforces large rate limits (≈1000 requests/min, 2 M input tokens/min, 400k output tokens/min for Sonnet/Opus)【23†L475-L483】, so per-minute throughput is ample for voice loops.

Importantly, Claude Agent SDK (the programming framework) still uses your plan’s quota (the planned token-credit system was paused)【3†L29-L37】. The SDK fully supports custom tools via MCP: you can register local or remote MCP servers either in-process or via shell commands【28†L285-L293】, and the SDK is built “MCP-first,” with mature tool integration like tool‐search and dozens of hook types【30†L260-L263】【28†L285-L293】. However, the current SDK has overhead: it spawns a new process per query(), adding ~12 s latency per call【67†L193-L201】, making real-time (<2 s) response infeasible using the SDK directly. (By contrast, direct Claude API calls are ~1–3 s.) In summary, Claude Pro/Max can power an assistant, but Pro limits are too low for 2k calls/day【16†L310-L314】, Max 20× (₹≈16,600/mo) is sufficient, and the Agent SDK is feature-rich but currently high-latency【67†L193-L201】.

## OpenCode (opencode.ai)

OpenCode is a popular open-source coding agent (MIT license) that runs in terminal or GUI. It is model-agnostic: it includes some free models and can connect to “any model from any provider” (Claude, GPT, Gemini, etc.) by plugging in API keys【32†L18-L21】【36†L255-L264】. It supports multi-session agents, code-specific tools, and MCP servers: you can configure both local and remote MCP tool servers, after which their functions are automatically exposed to the LLM【34†L99-L103】. OpenCode provides a JS/TypeScript SDK and can run headlessly: npm install @opencode-ai/sdk lets you embed a CLI/server instance in your own app【39†L123-L131】【39†L139-L147】.

The project is very active (≳195k stars, 950 contributors【32†L66-L74】) with frequent releases (latest v1.18.x in Aug 2026【40†L205-L212】). It has a rich tool ecosystem (LSP support, plan mode, image/text tools, etc.) and a user community (~16M monthly users【32†L66-L74】). In practice, OpenCode can drive voice-assistant prompts via its CLI/SDK using any free or paid model endpoint you supply. It supports ACP/MCP standards and has hundreds of community skills/extensions. The cost is effectively the cost of your chosen model: you can use free endpoints (e.g. our free proxies to Gemini, Groq, etc.) or your own API keys (OpenAI, Claude, etc.)【38†L257-L264】【49†L45-L53】.

## Other Agents/Frameworks

OpenAI “Codex CLI” (OpenAI Agents SDK) – A free CLI for GPT-based agents. Works similarly to Claude’s SDK: it plans with GPT-5. (Users run it via the OpenAI API or ChatGPT Plus.) Pricing is “basically the same” as a ChatGPT subscription【44†L270-L279】: ChatGPT Plus ($20/mo) gives GPT-4 access at that price; or you can pay per token. It fully supports multi-step tool chains (“agentic loops”)【44†L277-L284】 and since Sept 2025 it gained MCP support【44†L284-L290】 (though the ecosystem of ready MCP servers is smaller than Claude’s). In summary, Codex CLI is robust and free, but relies on your OpenAI/ChatGPT credentials and rate limits; 200 turns/day could exceed the free-tier ChatGPT limits, requiring a Pro plan or pay-as-you-go (₹≈1,660 for Plus per month).

Google Gemini CLI/API – Google’s API offers Gemini 2.5 Flash (and Lite) free on Tier-0: ~10 RPM, 250 requests/day (Flash) and 15 RPM, 1,000/day (Flash-Lite)【57†L47-L54】. These models are strong, but the capped request rates are very low for 200 calls/day (likely need Tier-1 paid upgrades). With a paid key, Gemini scale is up to 150–300 RPM. In practice the free quota is likely too small for sustained use【57†L47-L54】. (Note: actual throughput can fluctuate; some users report hitting limits under heavy load【57†L95-L102】.)

Open Interpreter – An open-source fork of Codex CLI tuned for open models (Kimi K3, Qwen, etc.)【47†L260-L268】. It installs via a simple script and provides a CLI (and editor integration via ACP). It ships optimized harnesses (in Rust) for each supported model to maximize speed (e.g. a Kimi K3 harness)【47†L240-L248】. It supports ACP, MCP, and can drop into any agent pipeline using the same Codex JSON protocol. Because it targets open models, one can use it with our free model proxies (Groq, Cerebras, etc.) with little cost. (Example: use Groq’s Kimi or Qwen to get state-of-art tool-calling.)

Goose (Agentic AI Foundation) – A new open-source agent framework (Apache-2.0) by Block. Goose offers a desktop app, CLI, and API【49†L29-L33】, built in Rust for speed and portability. It is general-purpose (not just code) and supports 70+ MCP extensions out of the box【49†L37-L45】. Goose works with any LLM provider (Anthropic, OpenAI, Google, local Ollama, OpenRouter, etc.)【49†L45-L53】, including using your existing Claude or GPT subscriptions via ACP. With 45k+ stars and 500+ contributors【49†L15-L23】, Goose is highly active. For our use case, Goose can run in the background (via CLI/API) and orchestrate multi-step toolchains with near-native speed. Its cost is just the model cost (and all major providers are supported).

DIY Loop (custom code) – Finally, one can bypass frameworks entirely by writing a custom agent loop. E.g. use Python or Node to call free LLM endpoints (via our proxy) step-by-step: ask model to pick tools, call tools via APIs, feed results back, etc. This is feasible with e.g. Groq or Cerebras APIs (which speak OpenAI format)【39†L137-L145】【55†L41-L49】. The overhead is entirely on you (implementing planning, state), but it avoids any framework latency. Tokens and rates remain those of the chosen model. Without a framework, you must also manage permissions, streaming, and context. This is the lowest-cost approach (no SDK fees), but requires more engineering.

## Free-Tier Model Reality and Tool-Calling Performance

Several LLMs are available at no cost (with rate limits) via our aggregated proxy:

GroqCloud – Provides many open models (Llama 3.1, 3.3, Llama-4 Scout, Qwen-3, Kimi-K2, etc.) with generous free quotas【53†L46-L54】. For example, Llama-3.1-8B has 30 RPM and 14,400 requests/day (with 500k tokens/day)【53†L46-L54】. Qwen-32B and Llama-4-17B each allow 60 RPM, 1,000 RPD (500k tokens/day for Qwen)【53†L46-L54】. Importantly, Groq hardware is extremely fast – advertised >500 tokens/sec on some models (an order of magnitude faster than typical GPUs)【53†L25-L33】. In practice, Groq’s free tier easily covers an assistant’s volume (hundreds of short calls/day) with very low latency. Among Groq’s models, Kimi (MoonshotAI K3) scores top on function-calling benchmarks【51†L207-L214】, so it would excel at multi-step reasoning.

Cerebras – The Cerebras API offers 1,000,000 free tokens per day (no card needed)【55†L41-L49】. Free users are limited to ~5 requests/min and 30k tokens/min with an 8k context cap【55†L50-L58】, and typically serve GPT-OSS-120B or Z-AI-GLM-4.7. The throughput is extremely high (Cerebras chips claim 20× real-time speed【55†L25-L33】). For a typical short prompt, the first response can come in <1–2 s on free Cerebras models. This free tier dwarfs other frees (1M tokens/day ≈ 33k tokens/hour) and easily supports ~200 turns/day.

Google Gemini (Flash) – The free Flash models (2.5 series) are high-quality but strictly rate-limited. E.g. Gemini-2.5 Flash: 10 RPM, 250 RPD (250k tokens/min)【57†L47-L54】; Flash-Lite: 15 RPM, 1000 RPD. The 1M-token context window is enormous, but only a few hundred queries/day fit. In practice, a Gemini free key might only sustain a fraction of 200 turns/day unless they’re batched. (Many developers report hitting less than 250/day during peak usage【57†L95-L102】.)

OpenRouter Free Models – OpenRouter offers a “free pool” of various open models (e.g. Dolly, Vicuna, openweights) but usage is very limited. New users get only ~50 free calls/day total across all free models【61†L392-L400】 (even if one adds 10 credits, it only rises to ~1000/day【61†L392-L400】). So OpenRouter’s free tier is essentially useless for a busy assistant.

Benchmarks (BFCL, etc.) – The latest leaderboards show Claude/K3/GPT-5 at the top of tool-calling accuracy【51†L207-L214】. Among free-access models, Groq’s Kimi (K3) would be best if available; Llama-3.3/70B or GPT-OSS-120B do well too【51†L207-L214】. Gemini-2.5’s tool-calling hasn’t been highlighted in recent leaderboards, suggesting it’s competent but not top-tier. In short, Groq and Cerebras free-tier models combine high speed with very strong multi-step performance (especially Kimi/Qwen variants【53†L46-L54】【51†L207-L214】).

## Latency Considerations

For voice interactivity, we need sub-2-second responses (ideally). Framework overhead and model speed both matter. The Claude Agent SDK itself adds ~12 s per query【67†L193-L201】, so avoid spawning new processes for each step. In practice, raw API calls or lightweight CLIs yield first-token times ≈1–3 s on small prompts. Notably, Groq’s LPUs process text at 500+ tokens/s【53†L25-L33】, so even a 500-token prompt can be generated in ~1 s. Goose (in Rust) and OpenInterpreter (native harness) minimize agent-side latency. We should use streaming output for fastest first token. In summary: use the fastest model/hardware and minimal middleware (Goose or Codex CLI hitting Groq/Cerebras) to get responses under ~2 s【53†L25-L33】【67†L193-L201】.

## Recommendation (Ranked Solutions)

1. Primary: Goose agent on free-tier Groq/Cerebras models. Goose is an open-source agent with native MCP/ACP support and a rich tool ecosystem【49†L37-L45】【49†L45-L53】. Run it headless via CLI or API, pointing at free Groq or Cerebras models through our proxy. For example, use Groq’s Llama/Qwen or Cerebras’s GPT-OSS via OpenAI-compatible endpoints. This yields zero rupee cost – both Groq and Cerebras tiers are free up to far beyond 200 calls/day【53†L46-L54】【55†L41-L49】. Groq’s speed (500+ tokens/s) and Kimi’s benchmark-leading tool-calling means very low latency and high reliability. Estimated cost: ₹0 (fits entirely within free quotas).

2. Fallback: OpenInterpreter (or Goose) with free models. If Goose setup is too heavy, use OpenInterpreter (or the OpenCode CLI) as the agent harness. For instance, OpenInterpreter + a free Groq/Cerebras model yields a similar zero-cost solution. It still supports MCP (and even has a QA skill/browsing)【47†L323-L332】. Alternatively, one could use the OpenAI Codex CLI with a free or trial OpenAI key, but beware free quotas are small. If needed, a ChatGPT Plus subscription ($20/mo, ~₹1.7k) can serve as a modest budget: it provides GPT-4 access with more lenient rate limits. Under ChatGPT Plus, 200 short-turn dialogues is feasible (the main limit is messages/5h). This would cost ~₹1700/month【44†L270-L279】 as a paid fallback if free options hit limits.

3. Offline / low-connect fallback: For truly zero-online cost or when offline, use a local LLM (e.g. Mistral-7B or Llama-2-7B running on your machine or via Ollama). These can answer simple queries (no external tools) but cannot call external APIs. Latency will be higher (especially on CPU), but they run at no cost. Combine with heuristics or cached info for robustness. This local mode costs ₹0 (only electricity).

Cost Summary: Using free providers, the monthly cost is essentially ₹0 for ~200 turns/day. If a small paid plan is acceptable, budget ~₹1700/mo for a ChatGPT Plus or Claude Pro subscription to add reliability. (Claude Pro alone likely isn’t enough capacity, so Max plans or pay-as-you-go would cost much more.)

Fallback Ladder: Primary agent (Goose/OpenInterpreter on free models) ➝ Secondary (ChatGPT Plus or Claude Pro + Agent SDK if absolutely needed) ➝ Offline simple LLM or manual handling if network/tools fail. Each step is progressively more limited but robust to budget or connectivity issues.
