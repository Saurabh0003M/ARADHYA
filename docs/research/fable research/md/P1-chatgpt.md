# Gaps and Unmet Needs

No shipped product currently meets all four criteria (voice input, full Windows desktop control, CPU-only hardware, free/nearly-free). Key missing capabilities include:

System-Wide Voice Control: Existing solutions (Microsoft Copilot, ChatGPT Voice, etc.) confine voice input to their own apps. A universally voice-driven UI layer (like true “Alexa for PC”) is not available. Microsoft’s Voice Access and earlier Cortana offered limited voice control, but they lack full NL/AI capabilities.

General Desktop Automation (Beyond Browser): AI agents that automate every app and window (not just web) are still in research. UI‑TARS and Agent S show vision-based potential but require powerful GPUs and technical setup. Cloud agents (ChatGPT’s “Computer Use”, Claude’s “Cowork”) can interact with screens, but only via their own interfaces.

CPU-Only Operation: Nearly all recent AI agents (ChatGPT Voice, Copilot Voice/Vision, UI‑TARS) rely on GPU or NPU for acceptable performance. A fully CPU-based LLM agent for UI tasks (let alone voice) is not practical today. Even “local” open-source agents like UI‑TARS or OmniParser assume GPU inference.

Free or Low Cost: Most shipping solutions are paid or cloud-based. Copilot and Gemini-in-Chrome are “free” to use but require internet and have usage limits; ChatGPT voice/agent require paid tiers; enterprise browser agents (Skyvern) are SaaS. The only free options (browser-use OSS, UI‑TARS OSS) lack voice and require technical skills.

Closest unmet needs (potential product gaps):

Local Voice Assistant for Windows: An open-source or free AI assistant that listens to voice commands globally and operates ANY desktop app (with fallbacks like “confirm before action”) on CPU hardware.

Offline LLM Desktop Agent: A self-hosted agent (like ChatGPT/Claude running fully locally) that understands speech and can navigate native UIs (without cloud). Current solutions (ChatGPT Voice, Anthropic Cowork) depend on cloud.

System-Wide “Hey AI” Wake Word: Unlike mobile Siri or Alexa, PCs lack a robust wake-word–triggered agent that then handles complex OS tasks. Windows’ “Voice Access” is rigid, and Copilot’s “Hey Copilot” exists but only in the Copilot app context and requires Microsoft’s cloud.

Free Multi-App Automation Service: A free/plans-cheap service that spans beyond browsers (e.g. controlling Office apps, email, local files) via natural language. All-in-one browser automation exists (Skyvern, BrowserUse) but desktop suites remain out of reach for free users.

Low-Reliability Billing: Many current agents can fail on complex workflows (e.g. unclear commands, dynamic GUIs). A gap exists in reliability and transparency (e.g. success rates on real tasks). Community-reported failures (agents mis-clicking, ignoring context) suggest no turnkey solution is proven yet.

In summary, no shipped product today offers all of (voice input + full desktop control + CPU-only + free). Every candidate covers some aspects (e.g. Copilot has voice but not CPU-only; ChatGPT Voice has voice but no system-wide control; UI‑TARS is local but no voice).
